# dreamASR Dashboard — полная дизайн-карта
> Инженерный чертёж в браузере. Белая бумага, чёрные линии в 1px, ноль скруглений, ноль теней, ноль градиентов. Вся выразительность — в типографике: один шрифт, один вес, огромные плотные заголовки со сжатым трекингом. Дашборд выглядит как печатный каталог швейцарской школы, а не как SaaS-панель.

**Тема:** светлая (единственная, тёмной нет — «тёмный режим» имитируется только инверсными блоками: чёрные плашки кода и инвертированные кнопки)

**Язык интерфейса:** русский (Intl.DateTimeFormat `ru-RU`, все подписи на русском)

**Где живёт:** React + Vite, один глобальный `styles.css` без CSS-модулей, классы по БЭМ-подобному соглашению через дефис (`.page-heading`, `.provider-badge.ok`). Все значения ниже — фактические из кода, менять их можно только осознанно.

---

## 1. Философия системы

Система **ахроматична**: чёрный, белый и три серых. Единственные цветные элементы во всём продукте — статусные рамки провайдеров (зелёный/янтарный/красный) и ничего больше. Иерархию строят не цвет и не вес шрифта, а:

1. **Размер** — заголовки страниц 58–120px против текста 16px.
2. **Отрицательный letter-spacing** — от −.02em до −.065em на крупном тексте, линии «слипаются» в плотные блоки.
3. **Линии** — `border: 1px solid #000` — главный структурный приём: секции не «карточки с тенью», а ячейки чертёжной сетки, разделённые волосяными линиями.
4. **Пустота** — 60–150px вертикальных отступов между секциями. Воздух — это роскошь, и система ей пользуется.

Вес шрифта **везде 400** — даже `<h1>`, `<th>`, `<b>` принудительно сброшены в 400. Единственное исключение во всём коде: `.dub-download { font-weight: 600 }`. Это не баг, а signature: ничто не «кричит».

Стрелка `↗` — фирменный глиф. Маркирует ссылки-действия («Открыть ↗», «Выйти ↗»), пустые состояния, навигацию.

## 3. Токены — типографика

### Manrope — единственный шрифт продукта
- **Подключение:** self-hosted через `@fontsource` (сборка отдаёт `manrope-latin-400-normal.woff2/woff`).
- **Вес:** 400 — единственный. Fallback: `Manrope, system-ui, sans-serif` (переменная `--font` задана прямо на `:root` и продублирована в `body, button, input, select`).
- **Даже `code` и `pre`** используют Manrope — моноширинного шрифта в системе НЕТ. Код отличается фоном `#000`/белым текстом, а не гарнитурой.
- **`font-synthesis: none`** — браузеру запрещено синтезировать жирность/курсив.

### Шкала размеров (фактическая)

| Роль | Размер | Line-height | Letter-spacing | Где |
|------|--------|-------------|----------------|-----|
| Hero (лендинг) | `clamp(64px, 10vw, 150px)` | .82 | −.065em | `.hero h1` |
| H1 (шапка страницы) | `clamp(58px, 8vw, 120px)` | .84 | −.06em | `.page-heading h1` |
| H1 (auth) | `clamp(55px, 7vw, 105px)` | .84 | −.06em | `.auth-layout header h1` |
| Результат транскрипции | `clamp(28px, 4vw, 55px)` | 1 | −.035em | `.result > p` |
| H2 секции | `clamp(40px, 5vw, 70px)` / 48px / 35px / 28px | .87–.95 | −.045em / −.035em | quickstart, api-reference, админка |
| Текст дропзоны | `clamp(30px, 4vw, 55px)` | .88 | −.04em | `.dropzone h2` |
| Stat-значение | `clamp(34px, 4vw, 52px)` | 1 | −.03em | `.stat-value` |
| Предпросмотр текста | `clamp(18px, 2.5vw, 26px)` | 1.25 | −.02em | `.result-preview .text` |
| Код endpoint'а | `clamp(18px, 2vw, 28px)` | — | — | `.endpoint code` |
| Body | `16px` | 1.15 | 0 | всё |
| Лид / hero-copy | `20px` | 1.1–1.5 | 0 | `.page-heading p`, `.hero-copy` |
| Бейджи, подсказки | `13px` | — | — | `.provider-badge`, `.picker-hint`, `.cell-sub` |
| Подписи, метаданные | `14–15px` | — | — | `.stat-label`, `.stage-label`, `.chip` |

### Правила
- Заголовки всегда «плотные»: line-height ≤ 1, отрицательный трекинг. Тело всегда «воздушное»: 1.15–1.5.
- Индекс страницы (`.index`, «01 / 05») — 16px, `#999`, ставится над H1.
- `::selection { color: #fff; background: #000; }` — даже выделение текста инверсное.

## 4. Токены — форма и отступы

- **Border-radius: 0 везде.** Глобальный сброс `* { border-radius: 0; }`. Единственное исключение: `.mode-tab { border-radius: 999px }` (пилюли-переключатели «Транскрибация / Дубляж») и круглый `.spinner`.
- **Бордеры:** только волосяные `1px solid #000`. Никогда серые бордеры у карточек (серый `#ddd` — только у неактивного mode-tab).
- **Тени:** отсутствуют как класс. Depth создаёт модальный оверлей `rgb(0 0 0 / 60%)`.
- **Сетка секций:** щедрые вертикальные ритмы — `padding: 75px 0 150px` у игровых зон, `margin-top: 60px` у таблиц, `150px` между рядами гридов.
- **Колоночные сетки:** overview/landing `repeat(3, 1fr)` с `gap: 20px`; playground `1.6fr 1fr`; quickstart `1fr 1.3fr`; usage-stats `repeat(4, 1fr)`; stats-grid `repeat(3, 1fr)`; админ-форма кредов `160px 1fr 1.4fr auto`.
- **Контентная колонка:** `.app-main { width: min(1240px, calc(100% - 150px)) }` — по 75px воздуха слева/справа под вертикальную навигацию. Лендинг — `max-width: 1440px`, паддинги `55px`.

### Контролы (точные размеры)
| Элемент | Геометрия |
|---|---|
| Кнопка `.button` | `min-height: 48px`, padding `12px 18px`, бордер `--line`, фон белый; hover → инверсия в чёрный; `:active` сдвигается на `1px` вниз |
| Кнопка `.button.primary` | Чёрная с белым текстом; hover → инверсия в белую; disabled → текст `#999` |
| Инпут / select | `min-height: 50px`, padding `12px`, бордер `--line`, плейсхолдер `#777` |
| Чип-фильтр `.chip` | padding `8px 18px`, активный — инвертирован |
| Бейдж `.provider-badge` | `display: inline-block`, padding `2px 8px`, font-size 13px, рамка `--line` |
| Спиннер | 14×14px, `border: 2px solid #ccc`, верхняя дуга `#000`, вращение .8s linear |
| Прогресс-бар | высота 4px, трек `#e5e5e5`, заливка чёрная, `transition: width .2s ease-out` |

## 5. Каркас приложения

### Публичная зона
- **Registration bar** — фиксированная полоса высотой 52px сверху: логотип слева, слоган по центру, «Войти ↗ / Регистрация» справа (grid `1fr auto 1fr`).
- **Лендинг** — hero на весь первый экран + сетка 3×N карточек-«этикеток» (номер, h2, описание, ссылка `↗`), разделённые только нижними линиями.
- **Auth** — две колонки `1.25fr 1fr` с разрывом 12vw: слева гигантский заголовок, справа форма с верхней линией и полноразмерной чёрной кнопкой.

### Приватная зона (дашборд)
- **Вертикальная навигация** `.edge-nav` — приклеена к левому краю (`left: 10px; top: 100px`), текст повернут `writing-mode: vertical-rl; rotate(180deg)` — читается снизу вверх. Пункты: Обзор, Playground, API-ключи, Журнал, Аккаунт (+ Админка для роли admin). Активный пункт — подчёркивание.
- **Аккаунт** `.edge-account` — вертикальная подпись в правом нижнем углу: username + «Выйти ↗».
- **Шапка каждой страницы** `.page-heading` — min-height 250px, нижняя линия; слева индекс `01 / 05`, H1, лид 20px; справа (или ниже) главная кнопка-действие.

### Страницы
1. **Обзор** — сетка 4 карточек-ссылок, quickstart с чёрным код-блоком curl, API-справка с `dl`-таблицами полей и списком моделей-кодов.
2. **Playground** — слева дропзона 430px (hover инвертирует всю зону в чёрное, глиф `↗` 55px справа сверху), справа fieldset с настройками (язык, модель, чипы мультивыбора моделей, toggle сравнения). Ниже: режимные пилюли, история загрузок (прогресс-бары, спиннеры, стадии), результат огромным текстом, compare-группа карточек для мульти-модельного сравнения. Режим «Дубляж» — тот же layout, асинхронные джобы со статусами и ссылками на скачивание.
3. **API-ключи** — инлайн-форма создания, при создании — чёрная плашка `.secret` с ключом и кнопкой копирования, таблица ключей.
4. **Журнал** — 4 stat-карточки, чипы диапазонов (Сегодня / Вчера / 7 дней / 30 дней / Все), разбивка по провайдерам, таблица записей (кликабельные строки → модалка деталей), «Показать ещё».
5. **Аккаунт** — `dl`-строки `1fr 2fr`, блок выхода.
6. **Админка** — stat-карточки, таблица здоровья провайдеров (загруженность, RPM, ошибки 24ч, cooldown), управление кредами (инлайн-добавление/редактирование/вкл-выкл/удаление), кредиты ElevenLabs, таблица ошибок (+ сводка дубляжа), пользователи, регистрация on/off.

## 6. Компоненты — точные рецепты

### Таблица
- `width: 100%; border-collapse: collapse; text-align: left`
- Ячейки: `padding: 16px 12px 16px 0`, нижняя линия `--line`, `vertical-align: top`, `min-width: 150px`
- `<th>` — `#999`; последняя колонка прижата вправо (`text-align: right; padding-right: 0`)
- Кликабельная строка — cursor pointer, hover `#f3f3f3`; обёртка `.table-wrap { overflow-x: auto; margin-top: 60px }`

### Модалка деталей
- Оверлей `position: fixed; inset: 0; background: rgb(0 0 0 / 60%); display: grid; place-items: center`
- Панель: `width: min(760px, 100%); max-height: min(760px, 90dvh); padding: 22px; background: #fff; border: --line`
- Заголовок и кнопка `×` в flex-строке с нижней линией; тело — `.detail-list` (grid `150px 1fr`, строки с линиями); сырой JSON — чёрный `<pre>` 12px

### Stat-карточка
- Бордер `--line`, padding `24px 20px`, flex-колонка с gap 10px
- Значение: `clamp(34px, 4vw, 52px)`, трекинг −.03em; подпись: `#999`, 15px

### Скелетон загрузки `.loading-rows`
- 3 полосы высотой 58px с нижними линиями; внутри каждой — серый брус `#999`, анимируемый `scaleX(.15 → 1)` 1.2s ease-in-out alternate, задержки .2s/.4s у второй/третьей

### Пустое состояние `.empty`
- min-height 300px, верхняя и нижняя линии, слева гигантский `↗` 55px `#999`, справа текст 35px line-height .9

### Сообщения
- `.message` — рамки сверху/снизу (без заливки), префикс `×`, `role="alert"`
- Ошибка провайдера в бейдже — рамка и текст `#c22`, без заливки красным

## 7. Моушн

Вся анимация — служебная, ≤ 1.2s, без ease-out «пружин»:

| Анимация | Параметры |
|---|---|
| Спиннер | `spin .8s linear infinite` |
| Скелетон | `load 1.2s ease-in-out infinite alternate` (scaleX + opacity .35→1) |
| Прогресс аплоуда | `width .2s ease-out` |
| mode-tab | `background/color/border-color .15s ease` |
| Кнопка `:active` | `transform: translateY(1px)` — мгновенно |

Обязательно: `@media (prefers-reduced-motion: reduce)` гасит всё до `.01ms` (уже в коде — сохранить).

## 8. Доступность

- `:focus-visible { outline: 2px solid #000; outline-offset: 3px }` — единственный допустимый focus-стиль.
- `.sr-only` для служебных текстов (статусы загрузки, подписи кнопок в таблицах).
- Кликабельные строки — `tabIndex={0}` + обработка Enter.
- Кнопки-иконки всегда с текстом (`×`, `↗` дублируются подписями или aria-label).
- Контраст: основной текст #000 на #fff — 21:1; вторичный #999 на #fff — ~2.8:1, допустим ТОЛЬКО для декоративных подписей, не для контента.

## 9. Адаптив (брейкпоинт один: 800px)

- Вертикальная навигация превращается в горизонтальную полосу внизу экрана (`height: 55px`, бордер сверху, горизонтальный скролл), edge-account скрывается.
- Все мультисетки схлопываются в 1 колонку (usage-stats — в 2), gap растёт до 80px между рядами overview.
- H1 — 58–64px; паддинги страниц — `100px 16px 90px`; код в quickstart — 13px.
- Регистрация-бар и навигация становятся `position: absolute`.

Дизайн-инвариант: между 800px и десктопом промежуточных состояний нет — сетки fluid через `clamp()` и проценты.

## 10. Правила для новых экранов (чек-лист)

При добавлении страницы/компонента в dreamASR:

1. Шапка — `PageHeading` с индексом `NN / 05`, H1 в `clamp(58px, 8vw, 120px)`, лидом и кнопкой. Индексы существующих: Обзор `01`, Playground `02`, Ключи `03`, Журнал `04`, Аккаунт `05`.
2. Ни одного нового цвета — только палитра из §2. Цвет разрешён исключительно для статусной семантики ok/warning/critical.
3. Ни одного border-radius (кроме пилюль-табов), ни одной тени, ни одного градиента.
4. Вес шрифта 400. Нужна выразительность — размером и трекингом, не жирностью.
5. Секции разделять линиями `--line` и воздухом 60–150px, а не карточками с фонами.
6. Данные — таблица по рецепту §6; метрики — stat-карточка; действия — `.button` / `.text-button`; фильтры — `.chip`.
7. Состояния обязательно: `.empty` для пустых, `.loading-rows` для загрузки, `.message` для ошибок, disabled-кнопка с `#999`.
8. Код/ключи/JSON — всегда чёрная плашка с белым Manrope.
9. Все интерактивные ховеры, где это уместно, — инверсия (белое ↔ чёрное), а не подсветка серым.
10. Не вводить иконки-библиотеки: единственные «иконки» системы — текстовые глифы `↗` и `×`.
